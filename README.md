# チャットミームメーカー

[ブラウザで開く](https://ny-an.github.io/chat-meme-maker/)

日常の会話をチャット画面風の画像にするミームメーカーです。開くたびに100本の会話例から見出しと会話が入り、キャラクターと表情もランダムで選ばれます。

- 見出し、相手の名前、自分の吹き出し、相手の最初の一言を編集できます。
- 「見出しと会話をランダム」で、その場で別の会話例に切り替えられます。
- 犬・猫・うさぎ・とら・龍を各15表情から選べます。持ち込み画像も使えます。
- 「PNGを保存」で2400 × 1350 pxの画像を書き出せます。

## ローカルで編集する

リポジトリを開き、下のコマンドを実行して [http://localhost:8000](http://localhost:8000) を開きます。

```sh
python3 -m http.server 8000
```

会話例は `conversation-topics.js`、編集画面は `index.html`、PNGの描画は `meme-maker.js` にあります。
